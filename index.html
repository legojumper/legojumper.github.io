Lab Projects

Hands-On Network Engineering

Every project below was built, broken, debugged, and documented from scratch on real Cisco hardware.

Advanced Routing

Multi-Protocol eBGP across Four Autonomous Systems

Designed a six-router topology spanning four autonomous systems, interconnected by eBGP. Each AS runs a different IGP — OSPF, EIGRP, and IS-IS — with full route redistribution and route-maps for policy control. Achieved 100% reachability across both IPv4 and IPv6.

eBGP OSPF EIGRP IS-IS Route-maps IPv6 Redistribution
OSPF

Multi-Area OSPF with Dual-Stack IPv4/IPv6

Configured a three-area OSPF network (backbone + two stub areas) across five routers and two Layer 3 switches. Implemented OSPFv3 for IPv6 routing alongside IPv4, verified inter-area reachability, and confirmed proper ABR and LSDB behavior.

Multi-Area OSPF OSPFv3 ABR LSDB Dual-Stack
Network Security

Layer 2 Attack Lab — Execute & Mitigate

Performed three distinct attacks on live Cisco hardware from a Linux machine: VLAN hopping via DTP manipulation (Yersinia), MAC table flooding (macof / dsniff), and ARP spoofing for man-in-the-middle monitoring. Then hardened each topology and verified mitigations rendered every attack ineffective.

VLAN Hopping MAC Flood ARP Spoof Port-Security DAI Wireshark
AI Infrastructure

Local LLM Server Accessible Over LAN

Deployed Ollama and Open WebUI inside Docker to host a local large language model (LLaVA 7B) accessible from any device on the local network — without sending data to external servers. Explored the privacy and security benefits of self-hosted AI for sensitive workloads.

Ollama Docker Open WebUI LLaVA WSL2
